## 0. על המסמך

המסמך משחזר את דרישות המערכת מתוך שתי מקורות:

1. **היסטוריית הבקשות** שהוזנו לפיתוח בין 15/09/2026 ל־04/10/2026 (15 בקשות מתועדות).
2. **קוד המקור והתיעוד שבתוכו** — שם מתועדות גם דרישות מוקדמות יותר שלא נשמרו בהיסטוריית הבקשות.

לכל דרישה מצוין מקור: **[ש]** = נאמר במפורש בבקשה מתועדת, **[ק]** = נגזר מהמימוש הקיים ומהתיעוד שבקוד. דרישות **[ק]** דורשות אישור של בעל המערכת — הן מתארות את מה שנבנה, לא בהכרח את מה שהוחלט.

סעיף 10 מכיל רשימת נושאים פתוחים הדורשים הכרעה.

## 1. מבוא

### 1.1 מטרת המערכת

מערכת לניהול ומעקב אחר דוחות נוכחות של עובדים, המיועדת למנהלים ולגורמי משאבי אנוש. המערכת מאפשרת לממונה לראות את מצב דיווחי הנוכחות של האוכלוסייה שבאחריותו, לאתר דוחות שטרם נסגרו או אושרו, ולשלוח תזכורות לעובדים.

### 1.2 היקף

שלב א' כולל שלושה מסכים: דף בית, דוחות נוכחות באחריות ממונה, ונתוני כל העובדים. המערכת היא **מערכת צפייה ומעקב** — פעולות העריכה עצמן (הזנת נוכחות, אישור דוח, צפייה בהיעדרויות/השתלמויות) מבוצעות במסכים חיצוניים שאליהם המערכת מנווטת.

### 1.3 מילון מונחים

| מונח | משמעות |
|---|---|
| ממונה / מנהל ישיר | העובד שהוא המנהל הישיר של עובד מסוים |
| כפיפים | עובדים שהמשתמש הוא המנהל הישיר שלהם (רמה אחת) |
| עובדי אגף | כל העץ מתחת למשתמש, כולל כפיפים של כפיפים |
| אוכלוסייה | סיווג העובד: משהב"ט / חיצוני / חייל / שירות לאומי |
| התקופה הפעילה | החודש שעליו המערכת עובדת — ראו דרישה BR-001 |
| דוח ישן | דוח שעדיין ממתין לאישור מחודש שכבר הסתיים |
